台灣桃園出發：日本京都五天四夜自助旅行完整規劃

京都是非常適合第一次前往日本自助旅行的城市。它兼具日本傳統文化、寺廟神社、古老街道、特色料理、購物商圈及自然景觀，而且可以透過步行、地鐵、JR、私鐵及公車完成大部分旅遊行程。

這次規劃以桃園國際機場出發、京都五天四夜、以步行觀光為主、搭配大眾運輸為原則。

我會將行程設計成兩種旅遊方式：

  1. 輕鬆步行型： 每天安排約 5～8 公里，適合想慢慢欣賞京都街景、拍照、品嚐美食的人。
  2. 深度健行型： 每天安排約 9～15 公里，盡量將相鄰景點串成完整步行路線。

另外，也會提供住宿選擇、餐飲選擇、交通費用概估、每日行程、注意事項及至少五項實用參考資源。

一、旅行基本條件與建議

旅行天數

5 天 4 夜

出發地

桃園國際機場 TPE

抵達機場

關西國際機場 KIX

住宿地點

京都市區連住 4 晚

旅行方式

步行＋電車＋地鐵

建議季節

春季或秋季

旅遊策略

  • 不每天更換飯店，減少行李搬運。
  • 以京都車站或四條河原町作為住宿基地。
  • 每天集中遊覽同一區域，減少交通時間。
  • 早上安排熱門景點，下午安排街道與文化景點。
  • 晚上以京都特色料理及散步為主。

1. 從桃園到京都的交通

優先選擇桃園直飛大阪關西國際機場的航班。

交通項目 建議方式
桃園至大阪 TPE 直飛 KIX
飛行時間 約 2 小時 30 分～3 小時
機場至京都 JR HARUKA
電車時間 約 80～100 分鐘
目的地 JR 京都車站

從關西機場搭乘 JR 特急 HARUKA 可以直達京都車站，不需要在大阪轉車。也可以選擇機場利木津巴士，約 90～105 分鐘，適合行李較多的人。

兩種交通方案比較：

方案 A：JR HARUKA

  • 優點：速度快、直達京都站。
  • 適合：希望節省時間的人。
  • 建議：預先確認優惠票及指定席。

方案 B：機場巴士

  • 優點：行李可以放在巴士行李艙。
  • 適合：攜帶大型行李或不想搬行李轉車的人。
  • 注意：可能受交通壅塞影響。

第一次去京都，搭 HARUKA 前往京都，回程則依航班時間與行李情況決定是否搭巴士。

二、京都住宿：建議住哪裡？

京都五天四夜，建議不要分散住宿，選擇交通方便、晚上有餐廳、附近可以步行的地方。

住宿區域主要有三個：

A. 京都車站周邊

交通最方便

  • 適合第一次到京都的人。
  • 往返機場、奈良、宇治方便。
  • 大型購物中心、餐廳及超市集中。
  • 缺點：傳統京都街道氣氛較少。

B. 四條河原町周邊

步行觀光最推薦

  • 鄰近錦市場、祇園、先斗町。
  • 晚上有許多餐廳。
  • 可以步行到鴨川及傳統街道。
  • 缺點：前往京都車站需搭車。

C. 祇園、東山周邊

  • 傳統京都風情最濃厚。
  • 適合喜歡清晨、夜間散步的人。
  • 靠近清水寺、八坂神社。
  • 缺點：住宿價格可能較高，部分路段交通不便。

2.1 實際住宿選項

以下是可以選擇的飯店：

步行觀光首選

  • 位於河原町、三條一帶。
  • 適合以祇園、錦市場、鴨川為主要旅遊範圍的人。
  • 現代化設計，周邊餐飲選擇豐富。

交通便利型

  • 京都車站附近。
  • 適合搭乘 JR 及機場快線。
  • 適合不想花太多時間研究交通的人。

Hotel Granvia Kyoto

  • 位於京都車站建築內。
  • 適合重視交通、服務與住宿品質的人。
  • 適合行李較多或同行有長者的旅客。

MIMARU KYOTO STATION

  • 公寓式住宿。
  • 適合家庭、多人同行。
  • 有較大的生活空間及簡易廚房設施。

Kyoto Century Hotel

  • 靠近京都車站。
  • 適合重視飯店服務及舒適度的人。
  • 可以減少每天進出車站的步行負擔。

住宿預算建議（每間房每晚，日圓概估）：

住宿類型 預算

中價位飯店 ¥12,000～20,000
中高級飯店 ¥20,000～35,000

這是規劃用的預算區間，並非上述飯店的即時報價。京都在櫻花季、楓葉季及日本連假期間，房價可能大幅提高，另外要把住宿稅納入考量。

住宿建議： 如果五天都以京都市區步行觀光為主，優先選四條河原町或三條；如果很重視交通與機場往返，選京都車站。

三、五天四夜每日行程規劃

整個行程採取「由遠至近、同一區域集中旅遊」的原則，避免每天花太多時間搭車。

第一天：桃園 → 關西機場 → 京都市區

主題：抵達京都、熟悉環境、輕鬆散步。

時間 行程 交通方式
07:00～09:00 桃園機場報到、出境 飛機
09:00～12:00 桃園飛大阪 飛機
12:00～13:30 入境、領取行李 步行
13:30～15:00 關西機場至京都 HARUKA
15:00～16:00 飯店入住 步行
16:00～18:00 錦市場、四條河原町 步行
18:00～20:00 京都特色晚餐 步行
20:00～21:00 鴨川散步 步行

以上是假設上午出發航班的示範時間，實際應依航班調整。

第一天下午：錦市場

推薦體驗：

  1. 日式玉子燒。
  2. 京都醃漬蔬菜。
  3. 日式烤海鮮。
  4. 抹茶甜點。
  5. 日式炸物及小吃。

注意錦市場並非所有店家都允許邊走邊吃，建議在店家指定區域用餐，不要拿著食物在狹窄通道行走。

第一天晚餐選項：

  • 平價：拉麵、日式定食。
  • 中價位：壽司、蕎麥麵、居酒屋。
  • 特色：京都湯豆腐、京都家常料理。

第二天：伏見稻荷大社 → 清水寺 → 二年坂 → 三年坂 → 祇園

最推薦的京都步行路線

這一天安排京都最有代表性的傳統文化與街道。

上午：伏見稻荷大社

建議 07:00～09:00 抵達。

伏見稻荷大社最著名的就是連綿不斷的紅色鳥居。

步行安排：

  1. 神社入口。
  2. 本殿參拜。
  3. 千本鳥居。
  4. 奧社奉拜所。
  5. 稻荷山部分步道。

兩種選擇：

方式 時間 步行強度
只走千本鳥居 1～1.5 小時 中
走到稻荷山頂再返回 2.5～3.5 小時 高

如果希望五天行程不太疲累，建議走到奧社奉拜所附近即可，不必一定登頂。

中午：前往清水寺

搭乘京阪電車或 JR，配合步行前往東山區。

清水寺是京都最具代表性的古寺之一。

建議參觀：

  • 清水寺本堂。
  • 清水舞台。
  • 音羽瀑布。
  • 周邊傳統商店。

建議停留約 1.5 小時。

下午：二年坂、三年坂

這裡是我認為京都最值得慢慢走的區域之一。

推薦體驗至少五項：

  1. 傳統日式町家建築。
  2. 京都陶器及手工藝品。
  3. 抹茶冰淇淋。
  4. 日式和菓子。
  5. 傳統茶屋。
  6. 八坂塔拍照。
  7. 京都特色紀念品。

傍晚：八坂神社、祇園

從二年坂、三年坂步行前往八坂神社，再進入祇園。

建議路線：

清水寺 → 三年坂 → 二年坂 → 八坂塔 → 八坂神社 → 花見小路。

這段路線約 3～4 公里，沿途可以充分感受京都傳統街道。

第二天餐飲設計

餐次 建議料理 預算
早餐 飯店早餐或日式早餐 ¥500～1,500
午餐 京都蕎麥麵、烏龍麵 ¥1,000～2,000
下午茶 抹茶甜點、和菓子 ¥500～1,200
晚餐 京都湯豆腐、京料理 ¥2,000～5,000

如果想安排一頓比較正式的京都料理，可以考慮祇園一帶的京料理餐廳，例如 Hanasaki Nishiki 或 Gion Kawakami，但這兩家價格定位較高，建議先確認套餐價格、訂位方式及用餐時間。

第二天步行量：

  • 輕鬆型：約 7～9 公里。
  • 深度型：約 11～15 公里。
  • 建議穿著舒適的運動鞋。

第三天：嵐山竹林 → 天龍寺 → 渡月橋 → 京都西部

主題：自然景觀、竹林、寺院與河川。

嵐山距離京都市中心較遠，建議整天安排在這個區域，不要再混入其他遠距離景點。

上午 08:00：抵達嵐山竹林

建議參觀：

  1. 嵐山竹林小徑。
  2. 野宮神社。
  3. 天龍寺。
  4. 曹源池庭園。

竹林建議早上前往，因為中午以後遊客通常比較多。

中午：嵐山特色午餐

可以選擇：

  • 湯豆腐套餐。
  • 蕎麥麵。
  • 鰻魚飯。
  • 京都日式定食。
  • 抹茶甜點。

建議預留 ¥1,500～3,000 作為午餐預算。

下午：渡月橋與桂川

渡月橋是嵐山著名地標，可以沿桂川兩岸散步、拍照。

建議：

  • 渡月橋步行。
  • 河岸拍照。
  • 嵐山公園散步。
  • 咖啡店休息。
  • 購買伴手禮。

第三天下午的兩種方案

A. 輕鬆休閒型

留在嵐山，沿河散步、喝咖啡、購物，約 3～5 公里。

B. 深度健行型

延伸至祇王寺、常寂光寺或愛宕念佛寺一帶，增加約 4～7 公里步行。部分路段有坡度。

第三天建議不要安排太多購物，讓雙腳適度休息。

第四天：金閣寺 → 京都御苑 → 錦市場 → 先斗町

主題：京都文化、歷史建築與購物美食。

上午：金閣寺

金閣寺正式名稱為鹿苑寺，是京都極具代表性的世界文化遺產。

建議參觀：

  1. 金閣寺入口。
  2. 金色舍利殿。
  3. 鏡湖池。
  4. 庭園步道。
  5. 茶屋及周邊紀念品店。

建議停留 60～90 分鐘。

中午：前往京都御苑

京都御苑適合喜歡自然景觀與安靜步行的人。

這裡與前幾天密集的觀光街道不同，有大片綠地、樹林及寬敞步道。

建議停留約 1～1.5 小時。

下午：四條河原町、錦市場購物

購物項目建議：

  • 京都抹茶。
  • 日本茶葉。
  • 日式陶器。
  • 和菓子。
  • 手工藝品。
  • 日本文具。
  • 生活用品。

晚上：先斗町與鴨川

先斗町是京都非常有特色的餐飲街道。

建議晚餐選擇：

  • 壽喜燒。
  • 日式燒肉。
  • 串燒。
  • 壽司。
  • 京料理。
  • 日式居酒屋。

如果想體驗較有京都風味的晚餐，可以選擇先斗町或祇園的餐廳。

第五天：京都早餐 → 最後採購 → 關西機場 → 桃園

第五天不建議再安排遠距離景點，避免錯過飛機。

時間 行程
07:30～08:30 早餐
08:30～09:30 飯店退房
09:30～11:00 京都車站購物
11:00～12:00 午餐
12:00～13:30 搭乘 HARUKA 前往機場
13:30～15:00 機場報到、出境
下午 飛回桃園

這裡假設回程是下午航班。實際應依航空公司規定及起飛時間，至少提前 2～3 小時抵達機場。

最後一天可以在京都車站購買：

  1. 抹茶餅乾。
  2. 京都限定伴手禮。
  3. 日式茶葉。
  4. 日本零食。
  5. 特色甜點。

餐廳選擇的五個原則

  1. 早餐以飯店或便利商店解決，節省時間。
  2. 午餐選擇當地特色麵食或定食。
  3. 下午安排一次抹茶或和菓子體驗。
  4. 晚餐選擇當地料理，不必每天吃高價懷石料理。
  5. 熱門餐廳提前訂位，避免把大量時間花在排隊。

五、步行旅遊與大眾運輸的兩種設計

這是京都自助旅行最重要的規劃之一。

京都的景點看起來很近，但實際上不同區域之間仍有距離，而且公車在觀光旺季容易塞車。因此，不建議全程依賴公車。

5.1 每日步行量設計

日期 輕鬆步行型 深度健行型 主要區域
第一天 3～5 km 5～7 km 市中心
第二天 7～9 km 11～15 km 伏見、東山、祇園
第三天 5～7 km 9～13 km 嵐山
第四天 5～7 km 9～12 km 金閣寺、市中心
第五天 2～3 km 3～5 km 京都車站

以上是規劃估計，實際會因住宿位置、進出車站、寺院內部參觀及購物而增加。

5.2 各種交通工具的用途

地鐵

適合南北、東西方向的長距離移動，例如京都車站、四條、烏丸御池及京都市中心。

JR 電車

適合京都車站往返伏見稻荷、嵐山及其他郊區。

市區公車

適合金閣寺、清水寺等距離車站較遠的景點，但要考慮塞車。

步行

適合祇園、清水寺、二年坂、三年坂、八坂神社及鴨川一帶。

5.3 交通票券怎麼買？

建議先使用 ICOCA 或其他適用的日本交通 IC 卡，依照搭乘路線直接扣款。

如果一天搭乘多次市區地鐵及公車，可以比較：

  • 京都市地下鐵一日券。
  • 京都地鐵及巴士一日券。
  • 京都、嵐山一日券。
  • 京阪電車京都觀光一日券。

京都市地下鐵及巴士一日券，官方旅遊資訊有提供相關票券介紹；購買前應確認當時價格、適用路線與使用範圍。

特別提醒：不要因為買了交通一日券，就強迫自己搭公車。

例如第二天的清水寺、二年坂、三年坂、八坂神社與祇園，步行通常比一直搭車更方便。

六、五天四夜旅遊預算

以下以一位成人、兩人同行共用一間雙人房為基準，使用日圓估算，再以新台幣概算。

匯率假設：¥1 = NT$0.22，僅供預算規劃，並非即時匯率。

6.1 各項費用

6.2 三種預算型態

類型 每人預算 旅遊方式
經濟型 NT$16,000～20,000 平價住宿、普通餐飲
舒適型 NT$21,000～28,000 中價位飯店、特色餐廳
品質型 NT$28,000～35,000+ 較好飯店、京料理及更多體驗

機票及飯店是變動最大的兩項。櫻花季與楓葉季可能超過以上預算，因此應先確定旅行日期再訂房、訂機票。

七、出發前必須準備的事項

7.1 護照及入境

  1. 確認護照有效期限及旅行期間的有效性。
  2. 台灣旅客持符合規定的台灣護照，短期觀光通常可免簽證入境日本。
  3. 可事先使用日本 Visit Japan Web 填寫入境及海關申報資料。
  4. 保存來回機票、飯店訂房資料。
  5. 確認個人藥品、食品及攜帶物品是否符合日本入境規定。

官方資訊：

  • 日本外務省
  • Visit Japan Web

7.2 手機及網路

建議在台灣先準備：

  • 日本 eSIM。
  • 或日本旅遊 SIM 卡。
  • 或 Wi-Fi 分享器。

我會優先推薦 eSIM，原因是不用另外攜帶設備，也不用歸還分享器。

建議選擇每天至少 1～2 GB 或依使用需求選擇較大的流量方案。

7.3 付款與現金

建議準備：

  • 信用卡。
  • ICOCA 交通卡。
  • 約 ¥20,000～30,000 現金。
  • 一張備用信用卡。

部分小型餐廳、傳統商店及寺院可能只收現金。

7.4 衣物及步行用品

至少準備以下物品：

  1. 好走的運動鞋。
  2. 輕便背包。
  3. 水壺。
  4. 行動電源。
  5. 折疊雨傘。
  6. 薄外套。
  7. 透氣襪子。
  8. 常備藥品及個人用品。

尤其第二天與第三天步行量較大，鞋子比漂亮的服裝更重要。

7.5 日本旅遊禮儀

以下幾點值得特別注意：

場合 注意事項
電車 不大聲講電話
餐廳 不隨意拍攝其他客人
神社 依現場規定參拜
祇園 不擅自拍攝藝伎或舞妓
住宅街 避免擋住居民出入口
公共場所 垃圾自行帶走或分類
公車 注意排隊及上下車順序
寺院 不隨意觸摸文物及庭園設施

京都觀光客很多，尤其祇園及東山地區，尊重當地居民生活是非常重要的事情。
